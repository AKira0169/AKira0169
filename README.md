## 📂 Open Source

Code you can actually read — every link below opens.

| Project | What it does | Stack |
|:---|:---|:---|
| **[Online Learning Platform API](https://github.com/AKira0169/onlineLearningPlatFrom)** ⭐3 | Course platform API. Uploads pipe straight into Cloudinary's chunked uploader — no temp file, memory bounded to one chunk. Playback is proxied as HTTP `206 Partial Content`, so clients can seek. | `NestJS 11` `MongoDB` `Paymob` |
| **[Claims Assistant](https://github.com/AKira0169/claims-assistant)** | AI-assisted insurance claims intake. A multi-step wizard with OpenAI-powered extraction from free text plus anomaly and completeness validation. | `NestJS 11` `Next.js 16` `Turborepo` |
| **[AI Voice Booking](https://github.com/AKira0169/ai-voice-booking)** | Outbound sales calling over a real-time voice pipeline — speech in, RAG-grounded answer out, speech back. | `Deepgram` `GPT-4o-mini` `Twilio` `Qdrant` `BullMQ` |
| **[Price Drop Notifier](https://github.com/AKira0169/price-drop-notifier)** | Zero-dependency embeddable alert widget. Renders in a Shadow DOM so the host page's CSS can't touch it, and falls back to an iframe when CSP blocks injection. | `JavaScript` `Express` `Tampermonkey` |
| **[Income Tracker](https://github.com/AKira0169/income)** | Personal finance tracker that runs entirely in the browser on a real SQLite database and exports a real Excel workbook. Fully offline. | `TypeScript` `SQLite` `XLSX` |
| **[KillPorts](https://github.com/AKira0169/killports)** | Windows GUI that finds and kills whatever is holding a port. Reads the kernel's TCP/UDP tables directly via `GetExtendedTcpTable` — no `netstat` spawn, sub-millisecond snapshot. | `C#` `Win32 API` |
